# StudyMate

**StudyMate** is a desktop-based study assistant application developed using C# and Windows Forms. It was designed to help students organize their academic activities and improve their study experience through a dedicated application.

This repository contains **StudyMate Version 1**, the original Windows Forms implementation. Version 2, a redesigned and modernized version of the application, is currently in development.

## Overview

StudyMate was developed as a software project focused on providing students with a digital tool to support their learning and study activities.

## Technology Stack

- **Programming Language:** C#
- **Framework:** .NET
- **Application Type:** Windows Desktop Application
- **UI Framework:** Windows Forms
- **Development Environment:** Visual Studio

## Project Status

- Version 1: Completed
- Version 2: In Development

## Getting Started

To run the application locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/StudyMate.git
   ```

2. Open the solution file (`.sln`) in Visual Studio.
3. Restore the required NuGet packages, if applicable.
4. Build and run the application.

## Future Development

StudyMate 2.0 is currently being developed as a new iteration of the original application, with a modern technology stack and an improved architecture.
